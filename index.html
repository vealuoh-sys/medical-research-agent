AutoMed PRISMA-DTA

An end-to-end medical research agent — literature search through publication-ready manuscript.

This page is documentation only. The working app runs as a live tool on Hugging Face Spaces, because it needs to run real Python (PubMed searches, LLM calls, statistics) — something GitHub Pages, as a static host, cannot do.

What it does, given one topic

  1. Searches PubMed for the topic
  2. Synthesizes themes & a research gap
  3. Proposes 5 candidate paper titles
  4. Runs a broader multi-query systematic search (up to ~100–200 papers) across PubMed & Europe PMC
  5. Screens papers against inclusion criteria
  6. Extracts 2×2 diagnostic accuracy data
  7. Runs QUADAS-2 risk-of-bias assessment
  8. Pools results with diagnostic meta-analysis, when the data supports it
  9. Drafts a full PRISMA-DTA manuscript with real citations
  10. Suggests real open-access journals via DOAJ

Run it yourself locally instead

The same pipeline runs from the command line, no browser needed:

python run_full_pipeline.py "your topic here"

Requires a free GROQ_API_KEY environment variable. See the README.md in this repository for setup.

Every citation, PMID, and journal this tool produces comes from a real API call (PubMed E-utilities, Europe PMC, or DOAJ) — nothing is invented. If a search or API call fails, the tool stops and says so rather than filling in placeholder data.
